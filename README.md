# SystemMonitor

macOS 13以降で動作する、CPU使用量とメモリ使用量を表示するメニューバーアプリです。

## 機能

- メニューバーにCPU・メモリの使用率を常時表示
- クリックするとCPUとメモリの使用量・残量・総量を表示
- アナログ／デジタル／ゲージの3表示を画面とメニューバーで同時に切り替え（選択は保存）
- メニューバーをダブルクリックしてmacOSの「アクティビティモニタ」を起動
- 詳細画面のメニューからmacOSの「アクティビティモニタ」を起動
- CPUまたはメモリの残量が20%以下になると赤色で警告
- CPUチップと2本の使用率ゲージを表した専用アプリアイコン
- メニューバーのデジタル表示は白文字、アナログ／ゲージ表示は白背景
- 2秒ごとの自動更新と手動更新
- 画面内の「終了」ボタン、または `Command + Q` で終了

## ビルド

```sh
cd SystemMonitor
chmod +x Scripts/build-app.sh
./Scripts/build-app.sh
```

完成したアプリは `build/SystemMonitor.app` です。Finderから起動できます。
ネットワーク共有上でmacOSの署名用拡張属性を保持できない場合に備え、同じフォルダへ
`SystemMonitor.zip` も作成します。署名済みZIPをローカルのMacで展開して利用できます。

通常利用するアプリは `/Applications/SystemMonitor.app` に配置します。

テストは次のコマンドで実行します。

```sh
swift test
```

CPUはホスト全体のCPU時間の差分、メモリはmacOSのVM統計におけるアクティブ・ワイヤード・圧縮メモリの合計を使用量として表示します。
